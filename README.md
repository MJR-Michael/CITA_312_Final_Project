# CITA-312-Final-Project
 
Game Overview:
This is a collection of minigames that play in a random order infinitely untill the player loses. A score is displayed at all times, and the player has only 3 lives untill they completely lose. Each game less is met with one less life, while each game win is met with a score increase.

Unfinished Features:
There were 2 games of out of the 7 total that had partial development but simply couldnt be brought to my satisfaction for final project submission. Some of the remnant files still exist, and a full scene can even be viewed within the files for one of the games.


Future Improvements:
